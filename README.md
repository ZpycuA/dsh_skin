# dsh-praze-skin

**Praze 主题皮肤插件 for DeepSeek Harness（dsh）** —— 把你的工作台变成 P 空间的一角：
自定义背景、右下角 Q 版鲸鱼娘桌宠（余额面板 / 峰谷价格）、Astra 风格思考强度滑条（档位吸附、拉满粒子爆发）、
模型展示、启动欢迎页，以及 P 空间粒子与计划树特效。

> 非官方社区插件，与深度求索（DeepSeek）无隶属、合作或背书关系。
> 「DeepSeek」名称与商标归其权利人所有。

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 🖼 自定义背景 | 使用包内本地插画作为工作台背景（经插件静态路由提供，不依赖外链 CDN；加载失败自动回退渐变底色）。只对最外层容器做半透明处理，**消息气泡、卡片、输入框保持原样**，不影响文字阅读。透出程度、柔化纱罩可调，一键「专注模式」完全还原 |
| 🐳 鲸鱼娘桌宠 | 右下角 Q 版 DeepSeek 娘（蓝发女仆 + 鲸鱼尾，AI 生成原创素材）。摸头触发开心表情 + 爱心粒子；点击身体打开发散菜单；**头像可直接拖动到任意位置**；可一键隐藏为小药丸，点药丸随时召回。所有浮层**互斥单开**：一次只弹出一个面板，默认只保留桌宠，不再向上堆叠遮挡视野；点外部 / 按 ESC / ✕ 即可收起 |
| 💰 余额面板 | 桌宠菜单打开：总余额 / 充值 / 赠金、可用状态灯、手动 + 自动刷新（间隔可调）、一键跳转官方充值页；面板内同时展示**当前接入模型** |
| ⚡ 峰谷价格对齐 | 按官方规则实时判定高峰/空闲（北京时间工作日 9:00–12:00、14:00–18:00 为高峰，周末与法定节假日全天空闲；调休上班的周末仍按周末），显示距下次切换倒计时；会话/今日费用按**事件发生时刻**的峰谷价格估算；进入高峰/空闲时桌宠气泡提醒（可关） |
| ✦ 思考强度滑条 | Astra（GPT-6 effort）风格发光渐变滑条：**可连续拖动并吸附到档位**，档位来自官方 `/models` 接口的 `effort.supported_levels`（接口不可用时用备用档位并明确标注）。档位名同时给出中文、Astra 别名与 Praze 耦合/借力释义；选档后经 `llm/stream` 钩子写入 `reasoning_effort`，下一次模型请求生效；拉到 MAX 触发金色粒子爆发 + 桌宠欢呼 |
| 📊 用量详情 | 本次运行的分会话 token 统计与费用估算（provider 真实 TokenUsage，去重累计：输入/输出/缓存读/缓存写/推理），在途调用可见，按当前模型与峰谷价估算 |
| 🏷 模型展示 | 余额面板、思考面板、用量面板与欢迎页均展示当前接入模型（在途调用优先，其次最近一次调用模型） |
| 👋 启动欢迎页 | 进入工作台时展示一张欢迎卡片：投射主题、当前模型、思考强度、能量储备与峰谷状态；点击「进入工作台」或 3.2 秒后自动消散，可在设置中关闭 |
| 🌌 Praze 特效 | P 空间低干扰漂浮粒子（后台自动暂停、遵循系统「减弱动态效果」）、模型工作时的「计划树」金色枝桠生长指示、四种投射主题配色（崇高蓝/神圣金/感召青/虚妄紫） |

## 安装

前置：已安装 DeepSeek Harness（Node.js ≥ 22、PATH 上有 `pnpm`），并能运行 `dsh web`。

```sh
# 本地目录安装（把路径换成本插件目录）
dsh plugin --profile web add file:/path/to/dsh-praze-skin

# 桌面版则用 desktop profile：
dsh plugin --profile desktop add file:/path/to/dsh-praze-skin
```

重启对应 profile 后，浏览器硬刷新（Ctrl+Shift+R）：

```sh
dsh web
```

卸载：

```sh
dsh plugin --profile web remove dsh-praze-skin
```

手动安装（备用）：把本目录放到 `$DSH_HOME/profiles/web/` 下，在其 `cordis.patch.yml` 追加：

```yaml
- insert:
    - id: praze-skin
      name: ./dsh-praze-skin/index.js
```

> 注意 `name` 指向入口文件而不是目录（DSH 加载器按 ES 模块导入相对路径）。

### 配置 API 密钥

余额、费用相关查询使用你在 DSH「设置 → 模型」里配置的 `DEEPSEEK_API_KEY`
（经 credentials 服务解析）。**密钥只在 Host 本机通过子进程环境变量传递，绝不进入浏览器、命令行或日志。**
未配置时余额显示「未配置密钥」，其余功能不受影响。

## 使用提示

- **背景透出程度**默认 32%：只在最外层容器做半透明，内部面板不透明，保证对比度。觉得花了就调低，或开「专注模式」。背景图走插件本地静态路由；若素材缺失会自动回退到渐变底色，不会出现空白。
- **思考强度**：`跟随` = 不干预会话默认；其余档位直接映射官方 `reasoning_effort`。档位列表实时来自官方接口，界面会标注「官方档位/备用档位」。
- **桌宠位置**：按住头像拖动即可，位置自动保存；「设置 → 桌宠」里可重置到右下角、调整大小或隐藏。
- **费用是估算**：按内置价格表（2026-11-14 官方口径）与事件时刻的峰谷状态计算，官方调价后请在「设置 → 价格」更新；一切以官方账单为准。
- **节假日表**内置 2026/2027 两年（国务院办公厅通知口径），可在「设置 → 价格」页编辑。
- 插件设置持久化在 `$DSH_HOME/storages/dsh-praze-skin/settings.json`。
- 本插件不含桌宠对话功能；不做任何遥测。

## 兼容性说明

- 按 dsh 开发者预览期（0.2.x）的公开插件通道实现：`webServer.register` / `tapIndex` /
  `session/event` / `llm/stream` / `credentials` / `subprocess`。dsh 处于快速迭代期，
  若未来接口变动，优先检查 `index.js` 中标注的这几处接缝。
- 思考强度注入仅作用于 DeepSeek 路由（provider/model 名含 deepseek），其他提供方不受影响。
- 背景半透明只修改最外层应用容器的背景色；若宿主主题结构变化导致背景不透出，可在设置里调高「透出程度」，不影响任何功能。

## 安全说明

- 所有路由仅由 dsh Web 服务暴露，默认绑定 `127.0.0.1`，仅本机可访问。
- API Key 不出 Host；浏览器端拿到的只有余额数字等结果。
- 静态资源路由白名单制，不存在任意文件读取。
